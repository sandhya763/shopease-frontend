# ShopEase Front End

A responsive vanilla HTML/CSS/JavaScript interface for the Shopping Cart internship task.

## Run it
1. Start the back end first (see `backend/README.md`).
2. Open `index.html` in your browser. If your browser blocks requests from a local file, serve this folder with a local static server, for example:
   - `python -m http.server 5500`
   - Then open `http://localhost:5500`
3. Keep the back end running at `http://localhost:5000`.

## Features
- Product listing with prices and categories
- Add/remove products and update quantities
- Live cart count and subtotal
- Checkout form with browser-side validation
- Responsive layout for mobile and desktop

This is a learning/demo checkout; it does not collect payments.
